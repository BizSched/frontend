# 용어집

화면 문구와 문서에서 쓰는 서비스 용어의 표기 기준이다. 같은 대상은 화면마다 같은 표기로 쓴다.

## 표기 기준

| 대상                 | 사용         | 쓰지 않음 | 이유                                                                       |
| -------------------- | ------------ | --------- | -------------------------------------------------------------------------- |
| 근무 일정            | 스케줄       | 스케쥴    | 외래어 표기법상 표준어. BE API 명세도 "스케줄"을 쓴다                      |
| 사장님이 고용한 직원 | 아르바이트생 | 알바생    | 줄임말을 서비스 용어로 쓰지 않는다. BE API 명세와 같은 표기                |
| 근무 형태·업무 영역  | 아르바이트   | 알바      | 위와 같다. 랜딩 카피(`알바 관리` → `아르바이트 관리`)도 예외 없이 적용한다 |

## 적용 범위

- 화면에 보이는 문구: 제목, 버튼, 모달, 빈 상태, 에러 메시지
- 화면에 보이지 않지만 사용자에게 전달되는 문구: `aria-label`, `alt`, 페이지 `metadata`
- `docs/` 문서 본문

다음은 적용하지 않는다.

- 코드 식별자(`schedule`, `staff` 등). 네이밍은 [naming.md](./naming.md)를 따른다.
- orval 생성 코드(`src/lib/api/generated/`). BE 명세를 그대로 반영한다.
- BE가 내려주는 에러 메시지 원문
- 테스트 mock 데이터의 이름 값(예: `김알바`)
