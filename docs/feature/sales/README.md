# 매출 기능 문서

## 개요

사장님이 월별 매출을 확인하고 날짜별 기록을 관리하는 기능이다. 첫 페이지 작업은 [매출 내역](./details.md)이며, 매출 대시보드는 별도 설계 후 진행한다.

## 주요 화면 / 플로우

| 화면                      | 라우트           | 역할                                                     |
| ------------------------- | ---------------- | -------------------------------------------------------- |
| [매출 내역](./details.md) | `/sales/details` | 월 선택, 월 합계와 날짜별 내역 조회, 매출 추가·수정·삭제 |

매출 내역의 첫 구현은 월별 조회에 집중한다. 추가·수정·삭제는 같은 페이지의 후속 단계에서 연결한다. 조회 조건은 월 하나이며 자유 텍스트 검색이나 카테고리 필터는 이번 범위에 없다.

## API 명세

현재 확정된 매출 API 명세가 없다. 조회·추가·수정·삭제 엔드포인트, 요청/응답 필드, 페이지 크기와 정렬, 월 합계 계산 기준, 날짜별 집계 책임, 카테고리 식별 방식은 API 연동 단계에서 백엔드와 확인해 이 문서에 기록한다. 예시 화면의 숫자와 카테고리명으로 DTO를 확정하지 않는다.

## 상태 관리 포인트

- 조회 월과 페이지는 URL 검색 파라미터로 관리한다. 월 변경 시 페이지를 1로 초기화한다. 1페이지 URL 표기는 [Pagination 설계](../../component/pagination/README.md)의 규칙을 따른다.
- 매출 목록과 월 합계는 서버 데이터다. 추가·수정·삭제 이후 갱신이 필요하므로 TanStack Query로 관리한다.
- 모달 열림과 행 편집 상태는 페이지 내부 상태로 둔다. 입력 폼 상태는 React Hook Form을 사용한다.

## 주요 컴포넌트

매출 내역의 월 선택은 기존 [MonthSelectDropdown](../../component/month-select-dropdown/README.md), 목록 페이지 이동은 [Pagination](../../component/pagination/README.md), 추가 진입점은 화면 크기에 따라 기존 [Button](../../component/button/README.md) 또는 [ActionButton](../../component/ActionButton/README.md)을 활용한다. 날짜별 행과 입력 폼은 매출 도메인 컴포넌트로 둔다. 공통 컴포넌트에는 매출 API나 집계 규칙을 넣지 않는다.
